# Amdox ERP

A full-stack HR Management System built using the MERN stack.

## Features

- User Authentication
- Role-Based Access Control
- Employee Management
- Department Management
- Designation Management
- Attendance Management
- Leave Management
- Payroll Management

## Technologies

- React.js
- Node.js
- Express.js
- MongoDB
- Axios
- JWT Authentication
